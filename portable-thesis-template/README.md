# Portable Thesis Template

Analyzes a school graduation thesis DOCX template and extracts portable formatting, structure, and workflow requirements for downstream Markdown and DOCX sync steps.

## Install

```powershell
npx skills add iuikj/portable-thesis-skills -a codex -s portable-thesis-template
```

## Trigger

```text
$portable-thesis-template
```
