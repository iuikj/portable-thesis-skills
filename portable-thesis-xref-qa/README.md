# Portable Thesis Xref QA

Audits and safely repairs thesis DOCX copies for figure and table captions, Word REF/SEQ/PAGEREF fields, bibliography citation fields, and citation superscript formatting.

## Install

```powershell
npx skills add iuikj/portable-thesis-skills -a codex -s portable-thesis-xref-qa
```

## Trigger

```text
$portable-thesis-xref-qa
```
