# Portable Thesis Markdown

Creates and maintains a git-backed Markdown thesis workspace that can later be synced into a school-template-based DOCX copy.

## Install

```powershell
npx skills add iuikj/portable-thesis-skills -a codex -s portable-thesis-md
```

## Trigger

```text
$portable-thesis-md
```
