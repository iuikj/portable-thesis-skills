# Chapter Plan Guidance

Use the school template and user preference first. If no structure is available, start with a conservative engineering thesis layout:

1. Introduction
2. Background or Related Work
3. Requirements and Analysis
4. System Design or Method
5. Implementation
6. Testing and Evaluation
7. Conclusion

## File Naming

Use sortable, stable filenames:

- `01_introduction.md`
- `02_related_work.md`
- `03_requirements.md`
- `04_design.md`
- `05_implementation.md`
- `06_testing.md`
- `07_conclusion.md`

Keep generated filenames ASCII when possible. The displayed chapter heading can use the user's language.

## Chapter Skeleton

Each chapter file should include:

- a top-level heading;
- a `<!-- template-notes: ... -->` comment for requirements discovered from the template;
- placeholder section headings only when the template or user preference supports them;
- figure/table writing notes when the template requires captions or specific numbering;
- citation writing notes when reference count or recency requirements exist.
