# Portable Thesis Env

Audits and prepares a portable thesis DOCX tooling environment, including Python tooling, optional virtual environments, package checks, and Office document tooling prerequisites.

## Install

```powershell
npx skills add iuikj/portable-thesis-skills -a codex -s portable-thesis-env
```

## Trigger

```text
$portable-thesis-env
```
