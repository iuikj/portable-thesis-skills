# Portable Thesis DOCX Sync

Syncs Markdown thesis draft changes into a protected copy of a school-template-based DOCX without rebuilding the document from scratch.

## Install

```powershell
npx skills add iuikj/portable-thesis-skills -a codex -s portable-thesis-docx-sync
```

## Trigger

```text
$portable-thesis-docx-sync
```
