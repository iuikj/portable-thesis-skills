# Portable Thesis Workflow

Coordinates the portable thesis skills for a reusable graduation thesis process: environment checks, DOCX template intake, Markdown drafting, DOCX sync, and cross-reference QA.

## Install

```powershell
npx skills add iuikj/portable-thesis-skills -a codex -s portable-thesis-workflow
```

## Trigger

```text
$portable-thesis-workflow
```
